Estos son los basics de HTML:

  <!DOCTYPE html> --> Marcado para que el navegador sepa que es una pagina web html. Se denomina nodo.



  Esqueleto basico:
    <html>
      <head>
        <title>Titulo de la pagina que luego sera el titulo en google</title>
        <meta charset = "UTF-8"/>
        <meta name="description" content="Aqui se pone el texto descriptivo que luego aparecera en google cuando se muestre nuestra pagina" />
      </head>
      <body>
        <header></header>
        <main>
          <section>
          </section>
          <section>
          </section>
        </main>
        <footer></footer>
      </body>
    </html>



  Imagenes <img src="ubicacion de la imagen" alt="descripcion de la imagen para SEO" title = "titulo descriptivo corto"/>  --> SIEMPRE poner ALT y si es imagen decorativa poner alt="", pero ponerlo igualmente. El TITLE es el mensaje que sale cuando dejas el raton encima de la imagen.



  Inputs y Labels ---> Un input debe tener siempre un label asignado. Se puede poner anidado o no (notese como funciona el elemento id en ese caso):
    No anidado
    ----------------------------------------------------------
    <label for="nombre-input"> Nombre </label>
    <input id = "nombre-input" type = "text" name = "nombre" placeholder = "Introduce aqui tu nombre completo"/>
    ----------------------------------------------------------
    Anidado (no hace falta id en input al estar autocontenido)
    ----------------------------------------------------------
    <label>
      Nombre
      <input type = "text" name = "nombre" placeholder = "Introduce aqui tu nombre completo"/>
    </label>



  Formularios --> Siempre deben tener un boton para hacer el submit del formulario. Si ningun boton lo especifica, el ultimo boton del formulario será automaticamente el tipo submit.
    <form>
      <label>
        Nombre
        <input type = "text" name = "nombre" placeholder = "Introduce aqui tu nombre completo"/>
      </label>
      <button type = "submit> Enviar </button>
    </form>



  Recordar usar las ETIQUETAS SEMÁNTICAS <section> <article> <header> <footer> <aside> <main> <nav>


  Las comillas en los atributos son opcionales SIEMPRE QUE NO TENGA ESPACIOS (por ejemplo un texto).
    <input type = text /> no es necesario "text"
    <img alt = "alt de mi imagen"/> aqui en alt si es necesario



  Comentarios en HTML <!-- Main Content Comment -->



  En las navegaciones hay enlaces internos (dentro de tu pagina) y externos (fuera de tu pagina). Es importante saber como definirlos:
    <nav>
      <a href = "#Experiencia">Experiencia</a>
      <a href = "https://google.com" target = "_blanck" rel ="noreferrer">Google</a>
      <a href = "tel:+346365558845"> Llamar a Fran </a>
    </nav>
    <h1 id="experiencia"> Mi experiencia personal </h1>

  Como se puede ver los enlaces internos buscan el "id" que coincida con el hastag que se le indica en href. En cuanto a enlaces externos, es importante indicarle que se abra en una nueva pagina con target = "_blanck" y evitar que se pasen datos de nuestro sitio web mediante rel ="noreferrer". Tambien hay una serie de patrones que tienen funcionalidad especial, como llamar por telefono, enviar un mail, enviar un whatsap, etc.



  Existe un atributo "role" para elementos que no tienen semantica, darsela. Por ejemplo en un div, podriamos tener:
    <div role = "alert">Esto es un mensaje de alerta</div>
  Hay muchos roles y se pueden ver en la documentacion, aunque si ya existe un elemento semantico es mejor utilizar este ultimo.



  Se puede hacer que un recurso nuestro (no externo) sea descargable para el usuario. Por ejemplo, con una imagen:
    <a download href = "/images/foto.jpg">
      <img src = "/images/foto.jpg" alt = "foto de fran">
    </a>
  El atributo download permite descargar el archivo cuando se le da click. Si la imagen fuera externa, lleva directamente a la imagen pero no la descarga.
